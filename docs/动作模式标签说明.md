# 抗阻动作模式标签

`data/exercise-movement-patterns.json` 是动作模式配置，键为稳定动作 ID；`movementPatterns` 为主要运动模式数组，目前每个抗阻动作有一个标签。热身和拉伸不使用该分类。标签描述主要动作形式，不表示医疗安全性、动作难度、完整肌群贡献或个人适用性，也不改变现有计划生成逻辑。

| 标签 | 含义 |
| --- | --- |
| horizontal_push / vertical_push | 水平推 / 纵向推（含臂屈伸） |
| horizontal_pull / vertical_pull / angled_pull | 水平拉 / 垂直拉 / 斜向拉 |
| shoulder_extension | 肩伸展 |
| shoulder_horizontal_adduction / shoulder_horizontal_abduction | 肩水平内收 / 水平外展 |
| shoulder_abduction / shoulder_flexion | 肩外展 / 肩屈 |
| elbow_flexion / elbow_extension | 屈肘 / 伸肘 |
| squat / lunge_step | 深蹲或腿举类 / 弓步及登台类 |
| hip_hinge / hip_thrust_bridge / hip_extension / hip_abduction | 髋铰链 / 臀推臀桥 / 其他髋伸 / 髋外展 |
| knee_flexion / knee_extension / calf_raise | 屈膝 / 伸膝 / 提踵 |
| trunk_flexion / trunk_lateral_flexion / trunk_rotation | 躯干屈曲 / 侧屈 / 转体 |
| trunk_anti_rotation / trunk_anti_extension | 躯干抗旋转 / 抗伸展 |
| hip_flexion | 髋屈，例如举腿、反向卷腹 |

主要模式相同并不意味着动作可以直接互换。斜向拉、臂屈伸等跨越多个运动方向；未来如要细化次要模式，应结合动作说明审核。新增抗阻动作时，先审核并维护映射，再运行导入；导入脚本在缺少映射时会停止。现有动作 ID 不变。
