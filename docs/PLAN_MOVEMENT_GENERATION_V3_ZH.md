# 计划动作生成 v3

新保存的计划采用 v3；已保存 v1/v2 计划和历史计划保留旧生成方式。生成成功时保存四周每日动作快照到 `fitlog-profile`，并随现有 fitlog 数据同步；重开或动作库后续更新不会直接改变已保存动作及其顺序。用户手动替换仍使用原有替换记录。

生成顺序：确定全身、上下肢或推拉腿结构 → 确定每一天需要的动作模式 → 从抗阻动作库按 `movementPatterns`、经验等级及指定的肌群类别筛选 → 收藏优先、再按器械和复合动作评分选择 → 应用重点部位 → 逐周参照上一周轮换 → 保存完整快照。初学者只选初级动作，优先固定器械及绳索器械；不再按固定名单排除动作。这些标签不证明用户掌握动作，器械可用性与动作熟练度暂未收集。必需模式无候选时停止新计划生成并提示。

轮换规则：每个训练日保留上一周前两项有主项标签的非重点附加动作；其他有辅助标签的动作每周最多替换两项，替代动作必须属于原动作模式、符合类别与等级并且当日不重复。主辅双标签动作在前两项之外可参与轮换；角色排序时仍按主项处理。没有合适替代时保留原动作并提示；重点附加动作保留且不能被普通动作占用。收藏只在符合筛选条件的候选中优先，不能覆盖模式、类别、等级、去重或轮换限制；无收藏时按原评分及 ID 规则选择。同分使用训练日序号和模式序号确定结果。收藏在生成时读取，之后变更收藏不修改已保存计划；历史重量依动作 ID 识别，不转移给替代动作。上述固定轮换数量是产品设计，不是教材规定每周必须换动作。

- 全身日：膝主导、髋铰链、上肢推、上肢拉、躯干抗旋转。
- 上肢日：水平推拉、垂直推拉、肩部辅助；下肢日：膝主导、髋铰链、屈膝、小腿。
- 推日：水平推、垂直推、胸部辅助、伸肘；拉日：垂直拉、水平拉、肩后侧、屈肘；腿日采用下肢动作模式。
- 专项爆发力动作及条件尚未审核，因此暂停新爆发力计划的生成；已有计划仍可查看。
- 有近期伤痛或用户填写动作限制时，不能从当前信息判断动作适用性，新计划暂停并提示咨询合格专业人士；高风险依然阻止生成。
- 初学者学习阶段组间休息 2–5 分钟；初学者力量目标先以动作学习阶段 8–12 次及试做组确定负荷，不能把经验或记录视为技术评估。

本版本尚不含器械可用性、动作熟练度评估、精确到小时的肌群恢复时钟或每周目标组数核算，不能据此宣称已全面实现教材所有规则。初学者新版计划按最终动作的主要肌群留至少一个完整日历日，训练时间只到日期，不能确认精确 48 小时。第 4 周文案不再声称固定减少 40%–50%，实际处方仍沿用既有周期公式；2-for-2 保持提示。
