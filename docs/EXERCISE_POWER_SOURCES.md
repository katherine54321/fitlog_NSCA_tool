# 爆发力动作来源

本批动作素材来自 [yuhonas/free-exercise-db](https://github.com/yuhonas/free-exercise-db) 的公开数据和图片；该仓库标注 Unlicense，项目对来源作记录。杠铃高翻、悬垂高翻、正向箱跳、徒手深蹲跳与药球胸前传球使用原库英文动作说明。原库 Push Press 条目没有英文步骤，因此杠铃借力推举的英文步骤由 FitMine 补写；所有中文步骤由 FitMine 编写。

本批分类为爆发力，供动作库检索与展示，包含举重衍生动作和跳跃、药球抛掷等动力性动作。分类不代表对每位用户适用；动作难度及指导需结合个人技术、身体条件和场地设备。动作不会因加入动作库而自动进入爆发力计划，相关计划仍处于锁定状态。

NSCA 的[训练方案示例](https://www.nsca.com/education/articles/ptq/time-efficient-training)包含深蹲跳、药球抛掷和悬垂高翻等动作；该文章用于参考动作类型，并非对本批数据、图片或训练计划的认证。
