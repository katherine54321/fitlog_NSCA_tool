# FitMine：教材导向的计划生成核对

整理日期：2026-10-29。本文为分析与待确认建议，不修改计划生成规则。

## 来源边界

产品以用户指定的《美国国家体能协会私人教练认证指南》卷二第 3 版及《NSCA-CSCS 美国国家体能协会体能教练认证指南》第 4 版为核心依据。NSCA 官方目录确认其英文《Essentials of Personal Training》第 3 版第 15 章为抗阻训练计划设计。CSCS 第 4 版及中文译本的章节编号、页码需要以实际书籍核对。参考：[NSCA-CPT 第 3 版目录](https://www.nsca.com/certification/nsca-cpt/essentials-of-personal-training--3rd-edition/)、[CSCS 第 4 版周期化摘录](https://dxpprod.nsca.com/education/articles/kinetic-select/central-concepts-related-to-periodization/)。

本次没有取得上述两本教材的抗阻训练计划章节正文。以下将**官方目录/公开教材摘录**、**其他 NSCA 文章**与**FitMine 产品实现**区分；不能据此宣布全部条目已通过指定教材的逐条符合性核验。用户先前提及的表格旨在说明不建议初学者每周训练 4 天，本文不把核验该表作为用户提出的独立任务。

## 一、现有固定模板究竟是什么

固定模板是 `index.html` 中预先编排的动作数组，而不是每次从完整动作库中按照条件动态计算的方案。选择目标、经验和天数后，程序确定全身、上下肢或推拉腿日程，并以训练日序号选择对应动作清单；四周通常沿用同一动作，改变每周组数、次数、负荷与休息。

以常规中级、增肌、每周 4 天为例：

| 日次 | 固定动作与当前顺序 |
| --- | --- |
| 上肢 A | 哑铃卧推 → 胸托哑铃划船 → 哑铃肩推 → 中立握高位下拉 |
| 下肢 A | 腿举 → 保加利亚分腿蹲 → 俯卧腿弯举 → 站姿提踵 |
| 上肢 B | 上斜哑铃卧推 → 单臂哑铃划船 → 哑铃侧平举 → 绳索下压 |
| 下肢 B | 杠铃臀推 → 罗马尼亚硬拉 → 哈克深蹲 → 坐姿腿弯举 |

基础选择完成后，程序按周套用处方；如选择重点部位，用动作名称及重点文字匹配，将找到的第一个重点复合动作提前，并在匹配程度最高的训练日尝试追加一个辅助动作。用户可替换动作；重复时用同类别候选动作及其肌群、复合/孤立和推拉属性做替换。热身和拉伸另根据当日动作文字识别。

**目前的限制：**模板内的顺序是人工预写，不会对每个用户重新检验器械是否可用、技术能力、完整的动力链/动作模式覆盖或各肌群恢复；重点复合动作是否提前依赖关键词匹配。爆发力目标当前使用通用动作数组，无法保证包含实际爆发力动作。高级 3 天非增肌计划的日程标题为推拉腿，但动作数组选择可能仍是通用全身模板，需要检查名称与实际动作的一致性。

相关代码：`makeSplit`、`makeHypertrophySplit`、`getWorkoutExercises`、`applyFocusEmphasis`、`ensureUniqueWorkoutExercises`。

## 二、核心计划要素与当前状态

CSCS 第 5 版官方目录列出的计划设计顺序为：需求分析、动作选择、训练频率、动作顺序、负荷与次数、训练量、休息。NSCA-CPT 第 3 版目录确认涵盖抗阻训练设计，器械章节公开摘录强调根据经验、动作熟练度、体型和偏好选取器械。[CSCS 官方目录](https://www.nsca.com/certification/cscs/essentials-of-strength-training-and-conditioning-5th-edition)、[NSCA-CPT 第 3 版器械摘录](https://www.nsca.com/certification/nsca-cpt/essentials-of-personal-training--3rd-edition/excerpts/types-of-resistance-training-equipment/)。以下是可核对的原则及实现差距，而不是声称逐字列尽教材原文。

| 核心要素 | 当前 FitMine | 初步判断与待确认优化 |
| --- | --- | --- |
| 需求、健康和目标 | 选择目标、经验、天数、重点；保存的高风险结果拦截生成；限制、睡眠及压力主要参与评估/提示。 | 高风险拦截已做；需要检查动作限制、器械和真实训练能力是否实际进入动作选择。教材与特殊人群的具体限制需对照原文。 |
| 频率与恢复 | 初学者 2–3 天全身并校验训练日间隔；4 天及以上被产品拦截。其他经验按 2–6 天分化。 | 符合以经验和恢复安排频率的方向；应检查实际受训肌群重叠。初学者 4 天限制按用户指定的产品策略保留，不在本次擅自改动。NSCA 公开旧版教材摘录对初学者全身训练给出 2–3 个非连续训练日的建议：[训练频率](https://dxpprod.nsca.com/education/articles/kinetic-select/determination-of-resistance-training-frequency/)。 |
| 动作选择与模式 | 固定数组，允许重点追加和用户替换，重复时同类别寻找替代。 | 缺少器械可用性、动作能力与动作模式覆盖的完整约束。需要为推、拉、膝主导、髋主导及躯干等建立明确标签；不宜把所有动作机械地归为同一种动力链。 |
| 排序 | 固定顺序，重点复合动作按文字匹配提前。 | 无法保证爆发力动作→主要复合→辅助的类别排序。NSCA 相关教练文章给出此常见顺序，同时可按目标及交替方式调整：[NSCA Coach](https://www.nsca.com/contentassets/6aed7b59b3b14393963319e30ff16c9e/nsca-coach-9.2--final--bonder.pdf)。建议验证重点提前时不破坏技术、安全和优先级。 |
| 负荷与次数 | 使用目标对应的固定 %1RM、RM、次数；初学者力量第 1 周 85% 和第 3 周 90–93%。 | 目标区间的方向可与公开资料对照，但固定百分比与次数不保证对个人或每种动作等价。初学者力量波动及爆发力计划需优先审阅；不能仅凭区间就判定适合每位用户。 |
| 训练量 | 按目标与经验给单动作组数，焦点额外加组；没有逐肌群每周目标与上限。 | 缺少可解释的肌群总量及主次肌贡献计算。每周 10–20 组是某篇 NSCA 出版文章对特定场景的一般参考，**尚不能认定为两本指定教材对所有人的统一硬性标准**。 |
| 组间休息 | 按目标给主项范围，最后一项辅助统一 45–60 秒。 | 固定按位置判断辅助动作可能覆盖实际动作需求，需按动作类型和训练目标核对。 |
| 变化、恢复及再评估 | 固定四周波动；第四周显示组数减少约 40%–50%，实际组数为 `max(2, 基础组数−1)`；中风险减组目前主要是提示。 | 恢复和变化方向合理，但提示与执行不一致，具体周期、比例与中风险处理需要核对来源并单独确认。 |
| 渐进建议 | 页面说明 2-for-2；另有依据本次记录及最后一组难度的建议。 | 按用户确认，**2-for-2 是加重建议提示，不增加连续两次的系统检查逻辑**。实际自动建议应清楚标注依据，避免让用户以为系统已核实该规则。 |

## 三、第 4 周减少 40%–50% 的查证

1. 本次未能访问两本指定教材中的相关正文，因此**不能确认这两本教材是否提出固定第 4 周减少 40%–50% 组数**。
2. NSCA 网站一篇针对女性消防员的署名文章，提出每第 4 周减少 40%–50% **训练量**的建议；这是特定人群的应用文章，不等于两本教材的普遍强制规则。其“训练量”也不能未经定义就直接等同于“组数”。[文章](https://www.nsca.com/education/articles/tsac-report/training-considerations-for-the-female-firefighter-bridging-the-evidence-gap-in-tactical-strength-and-conditioning/)
3. 另一篇 NSCA Coach 文章的示例将过渡周负荷设为 **40%–50% 1RM**，这是重量强度，与“总组数减少 40%–50%”不同。[示例](https://www.nsca.com/contentassets/d29cb11c8dd84c209dd8377fb3c71b3d/nsca-coach-10.1.1-integration-of-clean-variations-progressions-and-application.pdf)
4. 当前若基础组数 3，第 4 周为 2 组，相比基础周减少 33.3%；基础 4 则为 3 组，减少 25%；基础 5 则为 4 组，减少 20%。高级用户第 3 周可能是基础组数加 1，若以第 3 周为基准，比例又不同。辅助动作与重点动作还有各自的组数规则，所以不能把单个主项的比例等同于全周总量。

**建议先统一产品表述**：在取得指定教材依据前，不声称“教材要求第 4 周减少 40%–50%”。若决定继续保留第 4 周作为 FitMine 的恢复周，可按实际生成组数描述“适当减少训练组数并降低负荷”；是否改成明确的量化减量，应先确定比较基准、统计对象、最低组数与取整方式，并请专业人员审核。此处仅为建议，尚未修改。

## 四、建议的下一轮核对顺序

1. 将两本指定教材中关于需求分析、频率、动作选择、顺序、负荷/次数、组数、休息、进阶与周期的可核实内容整理为规则卡，并保留书名、版次、章节、页码及适用范围。
2. 为每条规则标明：明确要求、建议范围或示例；再对照各目标、经验和每周天数的实际生成结果。
3. 优先复核高风险及限制条件、初学者力量负荷、爆发力目标动作、分化标题与实际内容、同肌群恢复、减量文案与计算。
4. 对固定模板逐日审查动作模式及顺序，再决定保留经审定模板或引入标签驱动的组合与校验；先给用户确认实施方案。

目前已明确的冲突是**产品文案与代码计算不一致**；其余应区分“尚未覆盖”“可能不适合某人群”和“与指定教材明确冲突”，不在缺少指定教材正文时提前下结论。
